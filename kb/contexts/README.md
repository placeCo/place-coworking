# Lightweight contexts — для экономии токенов

**Цель:** боты грузят только нужный кусочек, а не весь `CANON.md`.

Используй эти файлы, когда задача узкая. Полный канон — только если этих файлов не хватает.

| Файл | Когда грузить | Размер |
|---|---|---|
| `prices-hours.md` | Цены, часы, Pass / Office / Podcast | очень маленький |
| `products-ban.md` | Что продаём, что запрещено, not-for-sale | маленький |
| `contacts.md` | Адрес, WhatsApp, сайт, IG, TG | микро |
| `bot-rules.md` | Что бот может / не может | маленький |
| `reception-short.md` | Краткие ответы ресепшена | маленький |

**Правило:** сначала эти файлы → если не хватает → `canon.json` → только потом `CANON.md`.

Все файлы ниже — выжимки из канона на 11.10.2026. Если канон изменится — обновляй их.
