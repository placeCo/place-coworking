## Как пользоваться в Tilda

1. Открыть проект **placecoworking.com** в Tilda.
2. Пройти **все страницы и языки** (EN / RU / ZH) — факты одинаковые.
3. Искать по Ctrl+F / Zero Block текст из колонки «Найти».
4. Снимать блок или править текст по «Поставить».
5. После правок — **не Publish** до OK George; лучше Staging / скрытая страница.
6. Spot-check §8 перед go-live.
