# End-of-shift report — PLACE Coworking

Status: FINAL · decided by George 15.10.2026 · replaces draft `docs/drafts/grok-out/2026-10-15-daily-report-format.md`

## Who / when
- **Who writes:** admins only — **Tangmo, Nathaly, Fon**. Other staff do not write this report.
- **When:** at the end of each own shift, before leaving (working hours 08:00–23:00).
- **Format:** exactly 3 lines, short text.

## Where posted
- Telegram group **PLACE Team**, as a normal message. **Group posts are in English only.**
- The TH/EN template below lives in the **pinned message** of PLACE Team (Thai is allowed only there, as a helper).
- Posting/pinning in Telegram is done by the **Lead bot**. Ops does not post.

## Template (pinned, TH + EN)
```
What I did / สิ่งที่ทำ:
Problem / ปัญหา:
What's needed / สิ่งที่ต้องการ:
```
Post in group (English):
```
Shift report — <Name>, <DD.MM>
What I did: ...
Problem: ... (or "none")
What's needed: ... (or "nothing")
```

## If missed
- No report by end of shift → Lead bot / George sends one reminder to that admin next morning.
- Admin posts the missed report the next day, marked "(late, for DD.MM)".
- Repeated misses (3+ in a week) → George discusses with the admin directly.

## How George sees a summary
- George reads PLACE Team directly, or asks Lead bot for a daily summary: per admin — reported yes/no, problems, needs.
- Optional (description only, not built): simple reminder script that checks at 23:00 whether each admin on shift posted a "Shift report" message and, if not, lets Lead bot send a reminder. No polling loops.

```
What I did: ...

What's needed: ... (or "nothing")

The template (TH/EN) is in the pinned message. If you forget, please post it the next morning marked "late". Thank you! 🙏
```
