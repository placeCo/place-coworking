- Canva / медиа под слоты календаря.
- Заполняет слоты в [SMM-календаре](https://docs.google.com/spreadsheets/d/1YjIN-j7jw_i-rCRdF_Xfpq2AD-ZIxKV1qAobmQH8ds8/) до статуса **«Готово»** (текст + медиа).
- Исполняет креатив по брифу; не придумывает цены вне канона.
- Публикация: только после пайплайна (календарь → OK George → Postiz draft при готовности → OK → publish). Postiz/Meta сейчас на паузе, пока календарь не заполнен и Meta login не сделан.

**Не делает:** менять публичные цены, логиниться в Meta без George, включать Postiz live без OK.
