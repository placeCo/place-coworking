# Telegram outbound — канон отправки (Place)

Любая исходящая от имени Place (DM, группа, канал-черновик для SMM/ресепшена).

## Порядок (обязательно)

1. **Написать полный текст** целиком (не кусками «на лету»).
2. **Literacy check** — орфография, цены = `CANON.md`, нет 5h@150, trial = 1 день этаж 3.
3. **Отправить** только после проверки.

Для **русского** предпочитать **clipboard paste** (не слепой ввод по символам) — меньше кракозябр.

Если ушло **искажённое** (кракозябры / битая кодировка):  
**сначала «удалить для всех»**, потом переотправить чистый текст. Не править поверх мусора.

- Отправлять полуготовый текст «потом поправим».

- Публиковать в канал/чат маркетинг без цепочки календаря + OK (см. `WORKFLOW-MARKETING.md`).
