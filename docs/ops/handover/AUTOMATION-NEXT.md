## Черновик 1: журнал поломок (`issues-log.gs`)
- Одна строка-хук в `poll()` bridge. Каждое новое сообщение в «Тех вопросы» становится задачей (`open`).
- Ответ (reply) с «готово / починил / fixed / เสร็จ / แก้แล้ว / ซ่อมแล้ว» переводит задачу в `closed`, любой другой ответ в `in_progress`.
- Колонки `Issues`: issue_id, opened_at_ict, floor, reporter, text, status, last_note, last_update_ict, closed_at_ict, closed_by, tg_chat_id, tg_message_id.
- `issuesDigest_('morning'|'evening')` даёт текст для 10:07 и 23:10. Бот в TG сам ничего не шлёт.
- `ISSUES_MODE=dry` по умолчанию: только лог, вкладка не создаётся. Проверено `dryRunIssues()` на тестовых сообщениях.
