# Чеки за бензин: наш формат (G-12)

Статус: **черновик, ждёт OK George** (30.09.2026). Решение George 30.09: формат **свой**, бухгалтер его не задаёт.

## Как сдаёт техник (одно сообщение боту или в «Тех вопросы»)

```
#fuel
Дата: 30.09.2026
Сумма: 500 ฿
Км / цель: 35 км, Makro + доставка воды
(фото чека во вложении)
```

Thai (для техника):

```
#fuel
วันที่: 30.09.2026
จำนวนเงิน: 500 บาท
กม. / เพื่ออะไร: 35 กม., ไป Makro + ส่งน้ำ
(แนบรูปใบเสร็จ)
```

## Поля

| Поле | Обязательно | Пример | Проверка |
|---|---|---|---|
| Дата | да | 30.09.2026 | не в будущем, не старше 30 дней |
| Сумма, ฿ | да | 500 | число > 0 |
| Км / цель | да | 35 км, Makro + вода | непустое |
| Фото чека | да | фото | есть вложение |
| Кто | авто | Som | из Telegram |

## Учёт

Бот (позже, по спецификации `#fuel` в [`D-DRAFTS.md`](D-DRAFTS.md)) пишет строку в лист `Bills` (`type=fuel`): дата, техник, сумма, км/цель, ссылка на фото.
Раз в месяц делается сводка: итог по технику и список строк. Она уходит **черновиком** на info@ для George/бухгалтера. Возмещает George.
Пока бота нет: техник шлёт сообщение в этом формате, Лена или Place Ops переносит строку в таблицу вручную.
