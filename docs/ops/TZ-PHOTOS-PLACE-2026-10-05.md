# ТЗ на фотографии — Place Coworking (Phuket)

**Дата:** 05.10.2026  
**Для кого:** съёмка / отбор кадров (Лена, фотограф, George)  
**Зачем:** каталоги (coworker.com, Deskimo, Office Hub, GBP, SMM), витрина Pass / Offices / Studio  
**Статус:** срочно — без 5 горизонтальных кадров блокируется coworker.com

---

## 1. Технические требования

| Параметр | Значение |
|---|---|
| Ориентация | **Горизонталь** (landscape), 3:2 или 16:9 |
| Разрешение | минимум **2000×1333**, цель **3000×2000** и выше |
| Формат | JPEG, sRGB, без водяных знаков |
| Вес | до ~5 MB на кадр (Deskimo ≤3 MB — сожмём сами) |
| Свет | дневной, без жёлтого «ночного» баланса; AC/лампы ок |
| Люди | по желанию 1–2 за работой (лица можно в профиль / спиной); без клиентов без согласия |
| Порядок | имя файла: `NN_зона_описание.jpg` (пример: `02_floor3_hall_wide.jpg`) |

**Не снимать / не отдавать:** крыша с перилами как «коворкинг», PLACE HOTEL, Farang, логотипы чужих брендов крупно, беспорядок на столах, закрытые двери «в лоб» без интерьера, вертикали для каталогов (вертикаль только Stories/Reels — отдельно).

## 3. Полный каталог (P1) — добить платформы с 8–12 фото

| Зона | Сколько | Содержание |
|---|---|---|
| Floor 3 — Pass hall | 3–4 | Широкий + средний + деталь розетки/стула/растения |
| Floor 1 — кафе / lounge | 2 | Стойка-ресепшен, посадка у окна |
| Floor 1 — библиотека | 1–2 | Стеллажи + место для чтения |
| Floor 1 — meeting rooms | 2 | Комната на ~13–20 и меньшая; экран 85″ если есть |
| Floor 5 — **private offices** | **по 1 кадру на каждый кабинет** | Дверь/номер (suite), стол, окно или без окна (свет!), вместимость до 6 |
| Floor 5 — terrace | 1–2 | Только если это **терраса 5 этажа**, не крыша |
| Floor 4 — studio | 1–2 | Подкаст/фото зона (после подтверждения, что это 4 этаж) |
| Атриум / лестница | 1 | Пространство здания, без «отеля» |

Архив отобранных: `/workspace/deskimo-photos/selected/` + Drive links в `selected_manifest.tsv`.  
Мелкие Alena-кадры офисов `1280×720` — **не для Worka/крупных каталогов**; нужны новые ≥2000 px по короткой стороне.

## 4. Офисы для Office Hub (P0 для листинга)

На **каждый** кабинет 5 этажа нужно:

1. Фото интерьера (горизонталь)  
2. От Лены текстом: suite №, **м²**, число столов, свет (окно / без / filtered), свободен с даты, цена 30 000 или занят  

Без м² + фото кабинет в Office Hub не заводим качественно.

Coworking desks (зал): 1–2 кадра зала 3 этажа + monthly 6 000 (форма каталога — Monthly, не day-pass).
