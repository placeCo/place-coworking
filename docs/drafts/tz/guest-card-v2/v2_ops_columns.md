# Place Ops — колонки таблицы под гостевую карточку v2

Админ заполняет карточку сам (2–3 вопроса гостю), в конце смены вносит в таблицу.

| # | Колонка | Тип / значения |
|---|---------|----------------|
| 1 | Date | дата (ДД.ММ.ГГГГ) |
| 2 | Time | время (ЧЧ:ММ) |
| 3 | Name | текст, можно только имя |
| 4 | Source | выпадающий список, 8 вариантов: Google Maps · Instagram · Telegram · Друг/Friend · Проходил мимо/Walked by · Листовка/Flyer · Сайт/Website · Другое/Other |
| 5 | Contact | WhatsApp/TG, необязательно (только если гость согласен) |
| 6 | Bought | текст (день / неделя / месяц / офис / подкаст / переговорная …) |
| 7 | Office interest | Y/N (выпадающий список) |
| 8 | Admin | кто заполнил |

Убрать из v1: «Зачем пришёл» (заменено на Bought), «сколько человек», «Позже», подписи «где взял листовку».
Листовку и Сайт пока оставляем (решение George 16.10), пересмотреть по данным.
