# Heavy TZ from bots

**Only for complex, high-token tasks.**

Bots write detailed technical specifications here when the task is too big or risky to finish in one run (long content plans, multi-step accounting packs, large site changes, deep audits, etc.).

## Rules

- File name: `YYYY-MM-DD-<role>-<short-topic>.md`
- First line: `DRAFT · needs George + Grok`
- Include: goal, current state, what is already known from canon, open questions, proposed steps, what should **not** be done.
- Do **not** invent prices, hours or ban-list items — reference `kb/contexts/CORE.en.md` or `CANON.md`.
- Keep the TZ itself reasonably structured so Grok can pick it up later without re-researching everything.

## What happens next

George asks Grok to pick up files from this folder. Bots do not implement the heavy TZ themselves unless explicitly told.
