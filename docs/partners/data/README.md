## Правила и оговорки

- Чеки: исключены отменённые (`cancelled_at`) и возвраты вместе с возвращёнными чеками (возврат был 1 раз — январь 2026). Чеки на 0 ฿ (бесплатные напитки, оплата из депозита баллами, WELCOME PASS) **входят** в число чеков и количество пассов, но net у них 0; их число — отдельная колонка.
- Net = `total_money` (после скидок). **Net включает поступления депозитов/авансов** (группа «Депозиты»: Deposit, Advance money), например 326 000 ฿ в октябре 2025. Это предоплата, не выручка от услуг; для питча её лучше показывать отдельно. Товары, оплаченные из депозита баллами, в net не попадают (это скидка «Discount by points»).
- Кафе/еда = кофе/чай, смузи, фасованные напитки, пиво, ланчи, завтраки, супы, десерты, снеки, мороженое, батончики (включая старые из категории OLD). Аренда/комнаты = все категории Rent*, Office rentals, переговорки, подкаст, аренда оборудования, Library rental.
- Уникальные клиенты — по `customer_id` среди всех действующих чеков за месяц (включая 0 ฿); в `monthly_summary.csv` есть также число клиентов с хотя бы одним оплаченным чеком. Чеки без клиента — гости без карточки, поэтому реальное число людей больше. В карточках есть персонал/владелец (бесплатные напитки) — они тоже считаются.
- Чего нет в данных: число посетителей/визитов (только чеки), загрузка мест, разбивка по этажам для новых пассов, доходы вне Loyverse (банковские переводы аренды без чека).

Файлы: `monthly_summary.csv` (все метрики по месяцам), `passes_by_type_monthly.csv` (пассы по типам), `passes_by_type.csv` (пассы по позициям Loyverse).
