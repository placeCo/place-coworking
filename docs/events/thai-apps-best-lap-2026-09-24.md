# Thai / Thailand-popular fitness apps для Place 1K Best Lap
**Для:** George (director)  
**От:** research brief  
**Дата:** 2026-09-24 (Asia/Bangkok)  
**Контекст:** Garmin Connect уже есть — аккаунт Place, публичный Course «Place 1K Best Lap», публичный Event, Finish/Smoothie course point у входа 59/2 Chao Fah Tawan Tok, Chalong.  
**Цель документа:** выбрать 1–2 платформы *после* Garmin с той же воронкой: flyer QR → join event/course → run/ride к Place → Finish → free smoothie + awareness coworking.  
**Метод:** WebSearch/WebFetch; цифры загрузок по Таиланду не выдумывать — либо цитата, либо **ASSUMPTION**.

---

## 1. Цель воронки (1 абзац)

Place Coworking (Chalong) хочет повторить модель Garmin на платформах, которыми реально пользуются бегуны/велосипедисты/номы на Пхукете: человек сканирует QR на флаере → открывает публичный course/event/route/segment в приложении → пробегает или проезжает ~1 км к Place (59/2 Chao Fah Tawan Tok) → фиксирует Finish у входа (Smoothie point) → получает бесплатный смузи и узнаёт о coworking. Критерий выбора: (а) есть публичный маршрут/событие или близкий аналог, (б) сильный охват в Phuket/Chalong или среди digital nomads, (в) QR/ссылка с флаера работает без тяжёлой разработки, (г) низкие затраты на сетап относительно Garmin.

## 5. What NOT to chase (низкий fit)

1. **Endomondo** — мёртв с 2020.  
2. **Apple Fitness+** — контент-подписка, не local course.  
3. **AllTrails** — trail/hike, не road 1K к офису.  
4. **Suunto / COROS / Polar Flow** как отдельные venue-каналы — узкая watch-аудитория; данные всё равно утекают в Strava.  
5. **Huawei Health / Samsung Health** — масс-health, нет сильного public Best Lap event.  
6. **MapMyRun** — слабый TH community (**ASSUMPTION**).  
7. **Ticketmelon / Race Roster** — ticketing overkill для free evergreen lap.  
8. **Relive как «join course»** — только post-share UGC.  
9. **Открывать своё поле We Run Thailand** ради 1K к Place — product mismatch (суббота/парк/≤5 км национальная сетка).  
10. **Adidas Running** как приоритет вне Бангкока — adidas Runners Bangkok ≠ Chalong.

## 6. Рекомендуемая последовательность (после Garmin)

**Уже есть:** Garmin Connect Place → public Course Place 1K Best Lap → public Event → Finish/Smoothie point.

### Сделать следующим

**X = Strava (неделя 1–2)**  
1. Club «Place Phuket» / «Place 1K Best Lap».  
2. Public Route ~1 км к 59/2 Chao Fah Tawan Tok (run + опционально ride).  
3. Public **Segment** с финишем у входа = leaderboard Best Lap.  
4. Club **Group Event** (тип Competition или Social) с привязанным Route; Discoverable on.  
5. Один QR на флаере: short link → landing (или напрямую Event); на лендинге кнопки Garmin + Strava.  
6. На стойке smoothie: «покажи Strava segment finish / Garmin course complete».

**Y = LINE OA + локальный промо (параллельно / сразу после X)**  
1. LINE OA Place: rich menu — Best Lap / карта / Garmin / Strava / «смузи за финиш».  
2. QR на флаере №2 (или тот же landing) → Add LINE для redeem + reminder.  
3. Посты в PhuketRun / локальные run-bike чаты + GBP/IG Stories с тем же QR.

**Затем (опционально)**  
- **Komoot** Tour для cyclists (тот же GPX).  
- **NRC** challenge как лёгкий эксперимент.  
- **Eventpop** только если решите делать датированный race day с регистрацией (не для evergreen lap).

**Не делать до доказанного трафика со Strava:** Huawei/Samsung/Apple Fitness+/AllTrails/Ticketmelon/свой We Run field.
