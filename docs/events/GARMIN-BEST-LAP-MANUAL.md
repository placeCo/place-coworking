# Garmin Best Lap 1K — мануал Place (сен 2026)

Кратко: в Garmin сначала курс, потом Event. Event без курса — просто дата в календаре. Смузи Garmin не выдаёт, это правило у стойки.
Адрес финиша: 59/2 Chao Fah Tawan Tok Rd, Chalong. Старт — конец Sports Street. Дистанция ~1 км.

## 0. Что создать
1. Course — линия маршрута на часах
2. Event — публичное событие в календаре + ссылка/QR
3. По желанию Segment — таблица лучших времён

Делать удобнее на компьютере: https://connect.garmin.com

## 1. Курс (маршрут)
### На сайте
1. Войти в Garmin Connect
2. Training & Planning → Courses → Create New
3. Тип: Running
4. Способ: Custom → Follow Roads
5. На карте поставить точки: старт — конец Sports Street; финиш — вход Place Coworking
6. Приблизь старт и финиш крупно, иначе дистанция поедет
7. Точки по желанию: Start, 7-Eleven, Finish / Smoothie
8. Имя, например: Place 1K Best Lap (первые 15 символов должны быть уникальными)
9. Приватность: Public — иначе не прикрепить к общему событию и не шарить
10. Save → Send to Device (на свои часы, чтобы проверить)

### В приложении
Ещё → Тренировки и планирование → Курсы → Создать курс
Дальше то же: Running → Custom → Follow Roads.
Проверь сам: активность Бег → Навигация → Courses → этот курс → Do Course. Должно быть ~1 км, финиш у здания.

## 2. Event (событие)
Лучше на сайте.
1. Calendar → нужный день (можно любой будущий; для постоянной акции бери ближайший понедельник)
2. Event → Create an event
3. Заполни:

| Поле | Что ставить |
|------|-------------|
| Name | Place Coworking Best Lap 1K |
| Type | In-person (не Virtual) |
| Location | 59/2 Chao Fah Tawan Tok Rd, Chalong |
| Distance | 1 km |
| Time | время старта или «весь день» |
| Website | Instagram / сайт Place |
| Visibility | Public / Visible to everyone |
| Course | прикрепи курс из шага 1 |

4. Add to Calendar
5. Если курсов/событий несколько — выбери это как Primary event, тогда на часах появится Race widget.

Курс для общего события должен быть публичным. Если спросит «сделать курс видимым для всех» — да.

## 3. Ссылка и QR
1. Календарь → это событие → View Event
2. Copy Link
3. Эту ссылку сажай в QR «GARMIN» на листовке

Гость открывает ссылку → Add to Calendar → синхронизирует часы → курс улетает на устройство.
Курс тоже можно шарить отдельно: Courses → нужный курс → Share.

## 4. Как гость пробегает этап
На часах Garmin:
1. Активность Run
2. Navigate → Courses
3. Place 1K Best Lap
4. Do Course
5. Встать на старте (конец Sports Street)
6. Старт записи
7. Финиш у входа Place
8. Сохранить активность

GPS должен быть включён с самого начала. Паузы на сегменте лучше не ставить.

## 5. Сегмент (таблица Best Lap) — по желанию
Event сам по себе не рисует рейтинг 3:08.420. Для этого:
1. Сами пробегите курс и синхронизируйте
2. Откройте эту активность
3. Segments → Create Segment
4. Ползунками отрежьте строго старт → финиш
5. Имя: Place Best Lap 1K
6. Public

Дальше у всех с Garmin, кто пробежит тот же кусок, время падает в таблицу.

## 6. Смузи — не в Garmin
На стойке одно правило:
Покажи активность с GPS: ~0.9–1.2 км, финиш у Place, сегодня.
Одна награда в день на человека. Не байк и не машина.
Не требуй «только Garmin». Телефон со Strava тоже ок.

## Частые ошибки
- Курс Private — ссылка и Event не работают нормально
- Event Virtual — это не ваш уличный этап
- Старт/финиш поставили мимо дороги — часы ведут дворами
- Имя курса начинается одинаково с другим (Place 1K...) — часы путают
- Гость добавил чужой Event, а автор удалил — событие пропадёт. Делайте своё Event, не чужое.
